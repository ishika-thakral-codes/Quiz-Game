# C Quiz Game

## Introduction
This is a simple Quiz Game developed using C programming language.

## Features
- 15 multiple-choice questions
- Mixed general knowledge questions
- Medium difficulty level
- Automatic score calculation
- Final score displayed at the end

## Language Used
- C Programming

## How to Run
1. Open the quiz.c file.
2. Compile the program.
3. Run the program.
4. Answer all the questions.
5. Check your final score.

## Project Type
Console Based C Project
